FarmersHub is a marketplace and community web platform that helps farmers present products and farm information while customers discover farmers, products, and supporting community features.

## Portfolio Snapshot

- **Target users:** farmers, local customers/buyers, and future agricultural service providers.
- **Problem:** farmers and nearby buyers often rely on fragmented channels, making product discovery, direct contact, and trusted farm information harder than necessary.
- **Final MVP:** a deployed static web client connected to a Node.js/Express/MongoDB API for authentication, role-aware experiences, profiles, products, posts, uploads, messages, and notifications. Several broader modules exist but still need complete end-to-end QA.
- **Final tracked frontend:** static HTML, CSS, and JavaScript in `frontend/`. The React migration appears in history and in an untracked local folder, but is not the submitted tracked frontend on this branch.
